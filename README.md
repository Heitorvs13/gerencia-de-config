# Gerência de Configurações

O objetivo do projeto é aprofundar os conhecimentos de configurações para softwares

## Controle de Versões

O *Controle de Versões* é parte fundamental pois permite trackear as alterações feitas, identificando o autor, quando e quais arquivos foram alterados, bem como as modificações feitas em detalhes.

A partir disso é possível então construir uma linha do tempo das alterações do projeto, dando a possibilidade de "voltar no tempo" para qualquer versão anterior.
